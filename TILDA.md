# HTML для Тильды

1. Открой файл [`tilda-embed.html`](./tilda-embed.html) (или скачай Raw).
2. Скопируй **весь** код.
3. В Тильде: добавить блок → **HTML-код** → вставить → сохранить.
4. Превью: [`tilda-preview.html`](./tilda-preview.html)

Картинки и шрифты уже с CDN `cdn.jsdelivr.net/gh/reklamixIvanovo/reclamix-assets@main`.
